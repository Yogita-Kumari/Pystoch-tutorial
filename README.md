# Pystoch-tutorial

This contains a Jupyter notebook to run pystoch. It is created for a tutorial on Stochastic Sources for a course on Foundations of Gravitational Waves: Theory, Sources, and Detection conducted 19 May-4 June 2026 at IUCAA, Pune.

Pystoch_instructions.pdf contains instructions for Pystoch to work.

Pystoch_requirements.pdf contains instructions to get scripts and data.
